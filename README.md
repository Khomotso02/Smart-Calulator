# Smart Calculator
A simple Python command-line calculator that performs basic arithmetic operations:
- Addition
- Subtraction
- Multiplication
- Division
It handles invalid input and division by zero using exception handling so it wont crash if the user enters the wrong data.
##How to run
1. Download or clone this repository
2. Make sure you have Python installed
3. Run the file in your terminal or IDE:
```bash
python main.py
